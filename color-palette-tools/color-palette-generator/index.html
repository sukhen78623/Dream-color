Free color palette generator for websites, apps, logos and more

Build a color palette from a single base color, a color harmony rule such as complementary, analogous, triadic or tetradic, a mood, a season or your brand. Choose a use case to get a palette arranged for a website, an app or UI, a logo, an interior or social media posts, and turn on the accessible option to keep text readable.

Every color shows its HEX code and how well text reads on it. Click a color to copy its HEX code, or copy the whole palette as CSS variables.

How to use the palette generator

  1. Pick a base color with the color picker or type a HEX code.
  2. Choose a mode: Base color, Harmony, Mood, Season or Brand.
  3. Choose a use case, such as Website or Logo.
  4. Turn on accessible only if the colors will carry text.
  5. Press Generate for new palettes, then copy the HEX codes or CSS variables of the one you like.

Palette modes

  • Base color: five balanced colors built around your color.
  • Harmony: complementary, analogous, triadic, tetradic, split-complementary or monochromatic schemes from the color wheel.
  • Mood: calm, bold, playful, elegant or natural palettes that start from your hue.
  • Season: curated spring, summer, autumn and winter palettes.
  • Brand: primary, secondary, accent, background and text colors from one brand color.

Frequently asked questions

How do I generate a color palette from one color?

Pick your color in the Base color mode and the generator returns five balanced colors around it. Press Shuffle for new variations.

What is the difference between complementary, analogous, triadic and tetradic palettes?

Complementary uses two opposite hues on the color wheel. Analogous uses hues that sit next to each other. Triadic uses three evenly spaced hues, and tetradic uses four hues made of two complementary pairs.

How do I choose a color palette for a website?

Select the Website use case. The generator assigns background, text, primary, secondary and accent colors. Turn on accessible only so the text stays readable on the background.

What does accessible only do?

It adjusts the text and background pair until the contrast ratio is at least 4.5:1, the WCAG AA level for normal text. For website, UI and social media palettes it also keeps the main colors at 3:1 or more against the background.

Is the color palette generator free?

Yes. The tool is free, needs no sign-up, and the palettes you create are yours to use in your projects.
