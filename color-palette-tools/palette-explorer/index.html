How to use the palette explorer

Pick a category, tap a color family dot, or type a HEX code to see the palettes closest to your color. Tap a color to copy its HEX code, tap Details for RGB and HSL values, similar palettes and a PNG download, and tap the heart to save favorites on this device.

Frequently asked questions

How are the color families chosen?

Each palette is grouped by its most colorful shade. Palettes with only soft, grayish colors go under Neutral.

How does closest to my color work?

The explorer compares your color with every palette color using a perceptual color model and sorts palettes so the nearest matches come first.

Can I make my own palette?

Yes. Use the Palette Generator to create palettes from any base color.
