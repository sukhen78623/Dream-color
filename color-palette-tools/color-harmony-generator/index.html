Questions


Color Harmony Generator FAQ


What is color harmony?
Color harmony is a set of guidelines for choosing colors that look good together. Each guideline picks colors from set positions on the color wheel.
Which harmony should I choose?
Complementary gives strong contrast and energy. Analogous feels calm and natural. Triadic is lively but balanced. Split-complementary has contrast with less tension. Tetradic and square give four colors, so let one lead. Monochromatic uses one hue in different lightness levels, which is clean and safe.
How do I use these colors in a design?
A common starting point is the 60-30-10 rule: about 60% a dominant color, 30% a secondary color and 10% an accent. Always check that text has enough contrast with its background.
Can I change the base color by dragging?
Yes. Drag on the color ring, use the Hue slider, pick a color or type a HEX code. All of them update the same base color.
Is my color data saved or uploaded?
No. The tool runs in your browser, and nothing you choose is sent to a server.
