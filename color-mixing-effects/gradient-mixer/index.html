How it works


Make a gradient in three steps




1. Pick your colors
Choose colors with the color box or type a HEX code. Add up to six colors.


2. Shape the blend
Switch between linear, radial and conic, set the angle and drag each color to its position.


3. Copy or download
Copy the CSS into your project, or download the gradient as a PNG image.







Questions


Gradient Mixer FAQ




What is the difference between linear, radial and conic gradients?
A linear gradient blends colors along a straight line at an angle. A radial gradient spreads colors outward from the center. A conic gradient sweeps colors around the center, like a color wheel.


How do I use the CSS in my website?
Paste the two lines into any rule, for example .hero { ... }. The first line is a solid fallback color for very old browsers, and the second is the gradient.


Is my gradient saved or uploaded?
No. The Gradient Mixer runs in your browser, and nothing you create is sent to a server.


Can I use the PNG commercially?
The PNG is generated from the colors you choose, so you can use it in your own projects.
